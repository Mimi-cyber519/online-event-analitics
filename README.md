# 🎪 OnlineEvent Analytics

> Аналитическая платформа для мониторинга активности участников онлайн-мероприятий

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.0+-red.svg)](https://streamlit.io/)
[![MySQL](https://img.shields.io/badge/MySQL-8.0+-orange.svg)](https://www.mysql.com/)

---

## 📊 Возможности

| Раздел | Что показывает |
|--------|----------------|
| 📅 Мероприятия | Список всех мероприятий |
| 👥 Участники | Список с фильтром по ролям |
| 📝 Журнал активности | Действия участников в хронологическом порядке |
| 📊 Опросы | Результаты голосований |
| ⏰ Проверки присутствия | Контроль посещаемости |
| ⭐ Отзывы | Рейтинги и комментарии |
| 🎯 Аналитика | 13 аналитических метрик |
| ✏️ SQL-запрос | Выполнение произвольных запросов |

---

## 🎯 Аналитические метрики

1. **Процент дошедших** (Show-Rate)
2. **Пиковая посещаемость**
3. **Топ активных участников**
4. **Анализ активности чата**
5. **Рейтинг мероприятий**
6. **Результаты контроля присутствия**
7. **Популярные варианты ответов**
8. **Скорость реакции на опросы**
9. **Анализ оттока** (ушли раньше)
10. **Вовлеченность по конференциям**
11. **Неактивные мероприятия**
12. **Поиск спаммеров**
13. **Рейтинг участников**

## 🚀 Запуск

### Windows
```bash
# Способ 1: Дважды кликнуть
run.bat

# Способ 2: В терминале
venv\Scripts\activate
streamlit run app.py
```

### Linux / Mac
```bash
# Способ 1: Запустить скрипт
./run.sh

# Способ 2: В терминале
source venv/bin/activate
streamlit run app.py
```

---

## 🗄️ Восстановление базы данных

1. Открыть **MySQL Workbench**
2. Server → Data Import
3. Выбрать папку `Dump/`
4. Нажать **Start Import**

## 🔐 Настройка конфигурации и паролей

1. В корне проекта перейдите в папку `.streamlit/`.
2. Переименуйте файл `secrets_example.toml` в `secrets.toml`.
3. Откройте `secrets.toml` и укажите ваши локальные данные для подключения к MySQL.
